Explain using the actual code and concrete examples. Start with the overall flow, then show the important implementation details. Point to relevant files and functions, and trace a concrete input through the code to its output or effect.

Define unfamiliar terms before using them, and use a small diagram where it helps. Distinguish what the code does from what you recommend changing. Do not modify files unless I ask.
