name: Hints, not solutions
description: Work through an exercise one hint at a time without revealing the solution
placement: append

Help me work through this exercise without giving the full solution. Ask what I've tried if needed, then give one focused hint at a time. Use the relevant lesson material and repository checkpoint. Do not edit the exercise or reveal the completed solution unless I ask.

When explaining code, use existing lesson code or a small analogous example rather than the exercise's completed solution.
